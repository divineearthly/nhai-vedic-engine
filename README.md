# 🌐 Divine Earthly: Sovereign Vision Engine (NHAI Edition)

An edge-native, fully offline biometric authorization matrix built for India's highway corridors and remote transit infrastructure. Designed to eliminate network dependency, reduce cloud API costs to zero, and secure citizen data through sovereign, on-device intelligence.

## 🚀 The Core Paradigm
Modern transit checkpoints rely heavily on cloud-based AI. When rural cellular networks fail, the entire toll infrastructure halts. **The Sovereign Vision Engine** solves this by moving all biometric verification natively to the edge. Raw optical matrices are analyzed, authenticated, and destroyed within milliseconds natively on the mobile CPU—guaranteeing 100% uptime regardless of internet connectivity.

## ✨ Key Architectural Features

* **🛡️ Sovereign JNI Memory Shield:** Eliminates the notorious React Native Base64 bridge bottleneck by streaming hardware optical frames directly to local storage and passing lightweight file paths to the C++ core.
* **⚡ Vedic Mathematics Optimization:** Utilizes high-performance C++ execution integrated with Vedic mathematical sutras (e.g., Nikhilam distance computation) to optimize structural algorithms for low-power ARM64 consumer silicon.
* **☀️ Photonic Lighting Armor:** Highway environments suffer from blinding headlights and harsh backlighting. The engine utilizes real-time Histogram Equalization (`cv::equalizeHist`) to mathematically balance extreme shadows before facial detection occurs.
* **🎯 Tactical Secure HUD:** A dynamic, React Native-driven graphical interface providing real-time matrix feedback, bounding box coordinates, and liveness verification metrics.

## 🛠️ Quick Start Deployment
```bash
# 1. Clone the repository
git clone [https://github.com/divineearthly/nhai-vedic-engine.git](https://github.com/divineearthly/nhai-vedic-engine.git)

# 2. Install Node Dependencies
cd nhai-vedic-engine/NhaiApp
npm install

# 3. Compile the Native C++ Sovereign Core & Android APK
cd android
./gradlew assembleDebug

```
## 🍏 iOS Cross-Platform Compatibility
The Sovereign Vision Engine is built on a unified React Native architecture, making it inherently cross-platform. To compile the engine for iOS devices (iOS 12+):
 1. Ensure Xcode and CocoaPods are installed.
 2. Navigate to the iOS directory: cd nhai-vedic-engine/NhaiApp/ios
 3. Install the C++ JNI bridge bindings: pod install
 4. Open NhaiApp.xcworkspace in Xcode and execute the build to deploy the sub-20MB edge model to Apple silicon.
